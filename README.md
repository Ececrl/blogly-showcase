# 💜 Blogly

**Herkesin kendi hikâyesini yazabildiği, okuyabildiği ve ilham verebildiği bir blog platformu.**

> 🚧 Proje erken geliştirme aşamasında. Kaynak kodu özel (private) bir repoda tutuluyor; bu repo projenin tanıtım sayfasıdır.

## Planlanan özellikler

- 🔑 Kayıt olma ve giriş yapma
- 🧑‍🎨 Kullanıcı adı (rumuz) ve avatar seçimiyle kişisel profil
- ✍️ Blog yazısı yazma ve yayınlama
- 📖 Diğer kullanıcıların yazılarını okuma

## Teknolojiler

- Python
- Streamlit (arayüz)
- Supabase (veritabanı ve kimlik doğrulama)

## Durum

- [x] Giriş / kayıt ekranı tasarımı
- [x] Supabase bağlantısı
- [ ] Kimlik doğrulamanın tamamlanması
- [ ] Yazı oluşturma ve listeleme
